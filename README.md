# Сайт загрузки «Континент: XVII век»

Публичный адрес: https://mark3543634.github.io/continental-xvii/

Откройте `index.html` или запустите локальный HTTP-сервер из папки `site`.

Локальные файлы для игроков находятся в `downloads/`:

- `continental_xvii_windows.zip` — Windows;
- `continental_xvii_android.apk` — Android.

Текущая опубликованная в папке версия: `0.1.1` от 2 августа 2026 года.

На публичном сайте кнопки ведут на файлы последнего GitHub Release.

Для публикации загрузите содержимое всей папки `site` на статический хостинг.
Из-за размера игровых файлов заранее проверьте ограничения выбранного сервиса.
